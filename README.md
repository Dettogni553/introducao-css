# Introdução ao CSS

Projeto de estudo sobre os fundamentos do CSS, criado na Aula 5 do curso de Análise e Desenvolvimento de Sistemas.

##  Conteúdo

- **index.html**: página com cabeçalho, lista dos tipos de seletores (elemento, classe e ID) e uma seção de containers com dois cards.
- **style.css**: folha de estilos externa com reset de margens, cabeçalho colorido e layout dos cards.

##  O que foi praticado

- Seletor universal (`*`) para resetar `margin` e `padding`
- Seletores de elemento, classe e agrupamento (`h2, ul, li`)
- Cores, bordas, fontes e espaçamentos (`margin`)
- Unidades de medida: `px`, `%` e `vh`
- Layout com Flexbox (`display: flex`, `justify-content`, `align-items`, `flex-direction`)
- Vinculação de CSS externo com a tag `<link>`

##  Tecnologias

- HTML5
- CSS3

##  Como executar

Clone o repositório e abra o arquivo `index.html` no navegador:
